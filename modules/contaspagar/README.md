# Módulo: Contas a Pagar

Títulos a pagar, plano de contas, despesas fixas, baixa, sync de notas do Genesis e BI por natureza e fornecedor.

- **Acesso:** todos veem; botões de escrita só para admin (`.rv-so-admin`) · Home → Módulo Financeiro
- **Entrada:** `initContasPagar()`
- **Dados:** `apps-script/contas-pagar.gs`. Guia de publicação e cron: `integracao/LEIA-ME-contas-a-pagar.md`
- **Bibliotecas:** Chart.js
