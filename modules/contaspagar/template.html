Como funciona. Cada linha é um molde, não um título. Ao gerar a competência, o sistema cria um título comum para cada conta vigente — que se edita, baixa e cancela como qualquer outro. Gerar o mesmo mês de novo não duplica nada: conta já gerada é pulada.
Mudou o valor? Edite o molde: vale do próximo mês gerado em diante, e o que já foi pago continua como está. Para corrigir um mês já gerado, edite o título.
